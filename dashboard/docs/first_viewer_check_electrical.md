`run_dashboard_electrical.bat`(자동 해설 모드)을 **소리 없이** 보여주고, 장면이 끝날 때 질문을 하나씩 한다. 정답은 화면에 있어야 한다.

| 2 ITSC 4턴 (0:20–0:45) | "어느 상이 문제고, 크기와 균형 중 무엇이 더 크게 바뀌었나요?" | R상. 크기는 132 %(위험)지만 균형 지표는 17배. | 막대 R만 빨강, 게이지 바늘 "4턴" 눈금, 자막 "정상의 17.3배", 회로도 단락 루프 |

## 조작 확인 (발표 전 1분)

- [ ] `L`(선/상전류 토글) 연타 시 막대 눈금·페이저 정격 원·회로도 값이 함께 바뀌고 색은 그대로인가
- [ ] 되감기·장면 건너뛰기(`1`~`7`) 직후 자막·이력·추세 커서·게이지·매트릭스 ◉ 가 같은 시각을 가리키는가 (`docs/sync_check.md`)
- [ ] `Space` 연타에서 자막이 중복되거나 회로도 입자가 멈춘 채 남지 않는가 (정지하면 입자도 멈추는 게 정상)
- [ ] `P` 로 페이저도가 크게 뜨고 `P`/`Esc` 로 닫히는가
- [ ] `Q` 서랍의 답에 `{…}` 가 그대로 보이지 않는가 (보이면 export 누락)
- [ ] 발표자 화면(`발표자 ↗`, `#/electrical/presenter`)이 "메인 화면 연결됨"인가
- [ ] `#/mechanical` → 첫 화면 → `#/electrical` 로 오가도 재생·자막이 새로 시작되는가
- [ ] 1366×768 노트북에서 세로 스크롤로 하단 4패널까지 보이는가

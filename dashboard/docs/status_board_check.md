## 동작 메모

- 재생은 시계 모드(`useClockPlayback`, `src/state/playback.ts`) — 영상이 없는 모터도 같은 Playback 인터페이스. 재생 바 배경은 시각별 판정 색.
- 게이지 색은 **현재값만의 등급**, 카드·머리글은 **판정 엔진 등급**(히스테리시스 5 %·지속 3 s). 둘이 다르면 게이지에 "판정 안전" 같은 점선 태그가 붙는다
  (예: 베어링 장면 초기 진동 4.8 mm/s 는 현재값 위험이지만 3 s 지속 전이라 판정은 안전).
- 전기 시나리오의 온도는 25 °C 고정(전기 데모와 같음), 기계 시나리오의 전류는 정상 100 %. 모드는 M 키 또는 "기계/전기 시나리오 ⇄" 로 바꾼다.
- 키: 1~5 모터 · Space 재생 · ←→ 장면 · M 모드 · F 발표 · Esc.

## 한계·보류

- 진동값은 결함별 상수(4.8/3.6/1.2/2.0/2.2 mm/s)라 5종 공통이고 규격(1.8 vs 1.4)만 다르다. 실측 연결 전까지 진동 판정은 모터 크기에 거의 무관하다.
- M1 은 온도만으로 위험에 닿지 않는다(결함 손실이 출력에 비례). 작은 모터의 결함 배율을 따로 둘지는 사용자 결정 사항 (`motor_dt_viz/docs/fleet_summary.md`).
- 해설 대시보드(기계·전기)의 영상·문구는 M5 기준이다. 다른 모터를 선택하고 이동하면 수치는 M5 의 것이 보인다 — 버튼 옆에 명시했다.
- 카드의 비선택 모터는 데모 위치에 고정된다(재생은 선택 모터만). 5종 동시 재생은 P5 라이브 모드에서 다룬다.

# 처음 보는 사람 테스트 체크리스트 — 기계적 결함 실시간 해설 대시보드

팀원에게 **소리 없이** 대시보드(`run_dashboard_mechanical.bat`, 자동 해설 모드)만 보여주고, 장면이 끝날 때 아래 질문을 하나씩 한다.
답이 기대와 다르면 그 장면의 해설 문구·자막·강조가 부족한 것이다. 정답은 화면에 있어야지 발표자의 말에 있으면 안 된다.

| 장면 | 질문 (소리 없이 화면만 보고) | 기대 답 | 답의 근거가 보이는 곳 |
|---|---|---|---|
| 1 정상 운전 (0:00–0:25) | "지금 이 모터는 문제가 있나요?" | 없다. 모든 부품이 제 색이고 온도가 허용 범위 안. | 상단 뱃지 "정상", 단면도 전부 회색, 해설 "기준선" |
| 2 DE 베어링 열화 (0:25–1:00) | "어느 부품이 문제고, VIGENT 는 언제 알았나요?" | 구동측(DE) 베어링 하나. 위험(빨강)이 되기 약 1.5초(시뮬레이션 약 3분) 전, 주의(70 °C)에 든 순간 경보. | 자막 "70 °C 돌파 — 주의 단계 (VIGENT 조기 경보 시점)", 온도 차트 주황 점선→빨간 선, 단면도 DE 베어링만 빨강 |
| 3 축 정렬 불량 (1:00–1:25) | "온도와 진동 중 어느 것이 먼저 문제를 알렸나요?" | 진동. 장면이 시작하자마자 진동이 '정비 계획' 등급, 온도는 축이 몇 초 뒤에 주의. | 진동 차트 계단과 마커, 해설 "온도보다 진동에서 먼저" |
| 4 냉각팬 고장 (1:25–1:50) | "어느 부품이 문제인가요?" | 특정 부품이 아니라 냉각(팬). 전체가 고르게 주황. | 단면도 전체 주황 + 냉각팬 X 표시, 지문 미니맵 4번, 해설 "부품이 아니라 냉각을 의심" |
| 5 브레이크 끌림 (1:50–2:10) | "열이 어디서 들어와 어디로 가나요?" | 브레이크에서 축으로, 축에서 로터로. 축이 먼저 붉어진다. | 단면도 열 경로 화살표(브레이크→축→로터), 손실열 막대 "샤프트 900 W", 지문 "축이 먼저" |
| 6 과부하 운전 (2:10–2:40) | "가장 먼저 한계에 닿는 부품은 무엇이고 왜인가요?" | 고정자 권선. 부하 135 % → 전류 증가 → 동손이 전류²에 비례. | 해설 "왜 그런가", 손실열 막대 권선(정격 대비 ×1.8), 온도 차트 권선 경고 마커 |
| 7 결함 해제 후 냉각 (2:40–3:00) | "정비하면 원래대로 돌아오나요? 그러면 VIGENT 는 왜 필요하죠?" | 돌아오지만 오를 때보다 느리다. 주의 단계 경보에서 정비하면 위험까지 가지 않아도 된다. | 온도 차트 하강 곡선, 해설 "그래서"(리드 타임), 인과 카드 "조치" |
| 전체 | "화면의 3분이 실제 3분인가요?" | 아니다. 화면 1초 = 시뮬레이션 60~150초(장면마다 다름, 상단에 표시). | 상단 시간 압축 표시(장면 전환 때 깜빡임), 툴팁 |
| 전체 | "이 온도는 실제로 잰 값인가요?" | 아니다. 시뮬레이션 기반 추정값(열회로 9노드 모델). | 상단 오른쪽 정직성 라벨 |

## 조작 확인 (발표 전 1분)

- [ ] 되감기(챕터 클릭, `←`) 후 해설 단계가 그 장면의 진행률에 맞게 다시 열리는가 (자동 해설 모드)
- [ ] 장면 건너뛰기(`1`~`7`) 직후 자막·이력·차트 커서·단면도 색이 같은 시각을 가리키는가 (`docs/sync_check.md`)
- [ ] `Space` 연타(재생/정지 반복)에서 자막이 중복되거나 사라지지 않는가
- [ ] `C`로 자막을 끄면 영상 아래 띠가 사라지고 영상이 커지는가, 다시 켜면 돌아오는가
- [ ] `Q` 서랍이 열리고 `Esc`로 닫히는가, 답의 숫자가 비어 있지 않은가(`{…}` 그대로 보이면 export 누락)
- [ ] 발표자 모드에서 `N` 세 번에 세 줄이 다 열리고, 장면이 바뀌면 다시 닫히는가
- [ ] 발표자 화면(`발표자 ↗`)이 "메인 화면 연결됨"이고 `Space`가 메인을 조작하는가
- [ ] 1366×768 노트북에서 세로 스크롤로 하단까지 보이는가

## 3. Maxwell 이 정하는 것 / 임계값이 정하는 것

- **Maxwell(RMxprt → MCCM/LUT → 2D FEM)이 정하는 것** = 결함 신호의 크기: 몇 턴이 붙으면 I₂/I₁·I_f·손실이 얼마인가(4턴 결함분 0.049, I_f 34 A, 158 W …). 시뮬은 이 값을 그대로 재현한다(≤ 0.47 %).
- **임계값(thresholds.yaml, 참고 데이터셋 provisional)이 정하는 것** = 판정 기준: 0.05 경고 / 0.10 위험, 3 s 지속. 같은 신호라도 기준을 바꾸면 판정이 바뀐다 — FEM 불확실성(I₂ +20 %)에서 판정이 바뀌는 시나리오 1건.

## 4. 한계

- 합성 신호(엔진 페이저 합성) — 실측 아님, 과도·RSH 없음. 고유 비대칭 0.027∠0° 는 가정(180° 면 4턴 경고 소실).
- 2D lite(학생판): 무스큐·분산 결함·단순화 기하 → Z₂ −16 %·역률 0.740; FEM 은 I_f·Z₂·정격 해·인덕턴스만 제공.

# 열회로 스케일 규칙 — M5(22 kW) 보정값에서 5종 모터로 (TASK_다중모터 §4.2)

`config/thermal.yaml` 의 노드 질량·열저항·정격 손실은 현 프로젝트 모터 M5(22 kW 6극, 180L)에 맞춰 역산한 값이다.
다른 모터는 새로 튜닝하지 않고 **출력비와 프레임 치수비**로 스케일한다. 규칙은 `engine/motor_library.thermal_cfg()` 한 곳에 있다.

| 양 | 규칙 | 근거 |
|---|---|---|
| 노드 정격 손실 `loss_W_rated`, 브레이크 끌림 `extra_loss_W` | × 손실비 = [P·(1−η)/η]_motor ÷ [P·(1−η)/η]_M5 | 전손실 ≈ 출력×(1−η)/η. 손실 배분(동손 35/철손 25/회전자 20/기계 15 %)은 모터 공통 관행 |
| 대기 열저항 `R_amb`, 노드 간 열저항 `R_ij` | ÷ geometry_scale² | 열저항 ∝ 1/표면적, 표면적 ∝ 치수² |
| 노드 질량 `mass_kg` (→ 열용량 C) | × geometry_scale³ | 질량 ∝ 부피 ∝ 치수³ |
| 단계 임계값, 결함 배율(손실 5배·방열 3.2배·부하 135 %), 듀티 사이클 | 공통 | 모터 고유값이 아님 |

`geometry_scale` 은 IEC 프레임 **축높이 비**(100L 0.556 / 132 0.733 / 160L 0.889 / 180L 1.0). M5 는 scale 1.0·손실비 1.0 이라 원본과
완전히 같다 (`tests/test_motor_library.py::test_m5_thermal_cfg_identical_and_steady_state_regression`).

손실비 분모는 M5 의 η=0.90 기준 2,444 W 다. (참고: thermal.yaml 노드 정격 손실의 합은 2,135 W 로 주석의 2,440 W 와 다르다 — 베어링 마찰손을
부하 의존으로 둔 결과. 비율만 쓰므로 스케일 결과에는 영향 없다.)

판정: 5종 모두 권선은 '정상' 상한(95 °C) 아래, 베어링은 70 °C 아래, 전 부품 F종 155 °C 안. 작은 모터가 더 낮고 더 빨리 데워지고 식는다
(시정수 36 → 64 분) — 물리적으로 타당하다.

**보고 사항(규칙을 고치지 않고 남김)**: M5 의 축·코어는 연속 100 % 운전에서 73~74 °C 로 '정상' 상한 70 °C 를 넘어 '주의' 띠에 든다.
이는 M5 원본 튜닝(프레임 ≈75 °C 목표)의 결과이며 듀티를 적용하면 48 °C 다. 테스트는 "권선·베어링 정상 + 전 부품 경고 미만"으로 둔다.

작은 모터는 결함 손실도 작고(손실비) 열저항은 커지지만 베어링이 식는 경로(축·엔드실드 전도)가 상대적으로 세서 더 천천히 오른다.
**M1 은 현재 시나리오 길이(장면 2: 35 s × 120배 = 70 분)에서 '위험'에 닿지 않는다** — P3 비교표에서 그대로 보고한다.
이것을 바꾸려면 결함 배율(공통)을 손대야 하므로 사용자 결정 사항이다.

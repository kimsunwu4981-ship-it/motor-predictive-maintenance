# 라이브 데모 대본 — 심사위원 앞 5단계 (TASK 실시간 §7)

준비: Isaac Sim 을 **통합 모드**로 라이브 실행(열·전류 결함을 한 화면에서 둘 다 주입할 수 있다), 대시보드는 같은 PC 또는 노트북.
```bat
C:\ISSACS~1\python.bat app\demo_integrated.py --gui --mode integrated --live --motor M5 --low
node dashboard\serve.cjs            →  http://<IP>:4173/#/status?live=ws://<IP>:8765&ctl=1   (K 키 = 제어 패널)
```
상단이 초록 `LIVE · M5` 인지, 제어 패널의 결함 버튼이 활성인지 확인. 녹화 백업 영상은 `모터결함_애니메이션/` (끊기면 자동으로 녹화 재생).

## 실패 시
- 띠 "라이브 연결 끊김 — 녹화 재생 중": 그대로 녹화 영상으로 설명을 잇고, Isaac 복구 후 자동 복귀를 기다린다(2 s 간격 재접속).
- 명령 거부 토스트(예: "scenario is playing — send stop_scenario first"): 제어 패널 ■ 시나리오 정지 뒤 다시.
- 모터 전환이 `restart_timeout_s`(120 s) 안에 안 돌아오면: 데스크탑에서 Isaac 창 확인 → `--motor M1 --live` 로 수동 재실행.

## 자동 재생 대본 (녹화·리허설용)
`python tools/live_demo_drive.py ws://<IP>:8765` 가 위 5단계를 같은 타이밍으로 보낸다 (1: 15 s, 2: 45 s, 3: 30 s, 4: 30 s, 5: 전환 대기 + 45 s). 녹화는 `tools/record_live_demo.ps1` (Isaac 창 + 브라우저 창을 함께 잡는 데스크톱 캡처 — 화면을 비워야 한다).

# M1(현대 HLP-2.2/4) 배치 시뮬레이션 요약 (엔진 기반, `tools/run_fleet.py`)

단일 모터 전환(2026-10-21): 등록 모터는 M1 하나다(M2~M5 는 `config/motors/_retired/`, 로더가 읽지 않음). 열회로 계수는 22 kW 보정값을 손실비·프레임 비례로 스케일한 것이라 M1 에서 낙관적일 수 있다(`docs/thermal_scaling.md`).

로그: `logs/fleet/<id>/<mode>/demo_fleet.csv`(데모와 같은 컬럼), `status_fleet.csv`(판정 엔진 결과). 시나리오·결함 파라미터는 공통,
결과 온도·전류는 모터 config(`config/motors/<id>.yaml` + 22 kW 기준 열회로(이전 기준, `config/thermal.yaml reference`) 스케일)로 정해진다. 시각은 **재생 시간(s)** 이고 괄호는
그 장면의 배속을 곱한 **시뮬레이션 시간(분)** 이다. 판정은 히스테리시스 5 %·지속 3 s 가 적용된 값이다.

## 물리 타당성 자동 검사

- 이상 없음 (작은 모터일수록 빨리 식고, 결함 도달은 느리다)
- M1: 기계 시나리오 전체에서 **온도**만으로는 '위험'에 닿지 않는다 — 위험 판정은 진동(시나리오 공통 상수 4.8 mm/s)이 만든다 (결함 손실이 출력에 비례해 작음, docs/thermal_scaling.md). 작은 모터의 결함 배율을 따로 둘지는 사용자 결정 사항
- 진동값(결함별 상수 mm/s)은 시나리오 상수다 — M1 규격은 ISO 10816-1 Class I(경고 1.8 / 위험 4.5 mm/s). 실측 연결 전까지는 진동 기반 판정이 모터 크기와 무관하다.

1. [ ] 다른 Isaac 인스턴스·불필요한 창·알림(카카오톡 등) 종료. **Isaac 은 하나만**(둘이면 전환이 2분 이상).

   콘솔 `[live] WebSocket ws://<IP>:8765` 와 `[perf] start: {fps…, vram_mb…}` 확인. HUD 에 `LIVE ws://<IP>:8765  clients 0`.
3. [ ] 대시보드 서버: `cd dashboard && node serve.cjs` → 콘솔의 `다른 기기에서: http://<IP>:4173/#/status` 주소.

5. [ ] 제어 패널에서 **리셋** 한 번(정상 상태 확인) → 카드 전부 초록.
6. [ ] 녹화 백업 영상 창을 **미리 열어 일시정지** 상태로 뒤에 둔다(아래 2절).

## 2. 라이브 실패 시 → 녹화 영상으로 전환 (목표 15초 안)
증상: 뱃지 "끊김 → 녹화"·노란 띠, 또는 명령이 계속 거부, 또는 Isaac 창 멈춤.
1. 말: "스트림이 끊겨 녹화본으로 이어 가겠습니다 — 같은 시나리오입니다." (대시보드는 이미 **자동으로 녹화 데이터**를 보여주고 있다 — 게이지·해설은 그대로 설명 가능.)
2. 영상이 필요하면 미리 열어 둔 **`모터결함_애니메이션/10_라이브_양방향_데모_1920x1080.mp4`** 창을 앞으로(Alt+Tab) → 재생. 타임라인: 0:15 정상 · 0:15~1:00 베어링 결함 · 1:00~1:30 턴간 단락 · 1:30~2:00 리셋 · 2:00 M1 전환 · 2:25~ M1 같은 결함.
   - 기계/전기 해설이 필요하면 `#/mechanical`·`#/electrical` 의 녹화 모드(영상+해설 동기)로.
3. 뒤에서 복구: Isaac 창이 살아 있으면 2 s 마다 자동 재접속 → 뱃지가 초록으로 돌아오면 라이브로 복귀. 죽었으면 1절 2번 명령으로 재실행(기동 ~50 s). 복구 뒤 **리셋** 한 번.
4. 모터 전환이 안 돌아오면(띠 2분 넘게): Isaac 을 `--motor M1` 로 수동 재실행하거나 영상 2:00 이후로 대신한다.

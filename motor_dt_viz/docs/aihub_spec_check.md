**4.7 A 와 8.6 A 가 갈리는 이유**: 헤더 키에는 모터명·rpm·kW·A 네 값뿐이고 전압·결선·기종 키가 없어 JSON(헤더)에서는 이유를 확정할 수 없다. 헤더 값의 조합은 (1760 rpm, 4.7 A) 6대 / (1730 rpm, 8.6 A) 2대(시청역 L-DEF-01·L-DSF-01)로 **rpm 까지 함께 갈리므로 기종(명판) 차이**로 읽히지만, 전압 차이인지는 데이터에 근거가 없다(추측 안 함). 덧붙여 전류 파일 헤더는 같은 모터인데 다른 값(L-EF-04 1730/8.2 A, R-EF-05 1730/14 A)을 적고 있어 **헤더 사양값 자체의 신뢰도가 낮다**. L-EF-04 는 갑천역·대전역에 같은 이름의 모터가 하나씩 있어(센서 2개) 한 이름이 두 기기를 가리킨다.

테크니컬 리포트의 수집 서버 스키마에는 `motor_specification(object)`, `stress_specification(정토크/2승저감)`, `serial`, `is_ground_truth` 가 있으나 **배포 CSV 헤더에는 실리지 않았다**.

## 확인 3 — 정상 파일 I₂/I₁·상 불평형 참고 분포 (3상, 계산만 — 설정 반영 안 함)

모터당 정상 파일 ≤500 무작위(seed 1). I₂/I₁ = 60 Hz 기본파 3상 페이저 → 대칭 성분(`tools/aihub/extract_features.py i2_over_i1`, 큰 쪽을 정상분으로). 상 불평형 = max|I_rms,k − 평균| / 평균. 경계: I₂/I₁ 경고 0.03 / 위험 0.10(`config/thresholds.yaml i2i1`), 상 불평형 경고 0.05 / 위험 0.10(지시서 값 — config 에는 없음; config 는 정격 대비 전류비 0.85~1.10 만 있음).

읽는 법
- L-EF-04·R-EF-05 는 I₂/I₁ 0.026~0.028 에 상 불평형 3 %로 "정상이 경고 경계(0.03) 바로 아래"다 — 경고 0.03 이면 정상의 23~31 %가 경고로 찍힌다. 55 kW 인버터 2대는 0.005~0.034 로 갈린다.
- L-SF-04 는 S상 RMS 가 다른 상보다 10 % 커서(3.40 vs 3.08/3.11) I₂/I₁ 0.088 — 공급 불평형인지 전류센서 채널 게인 차이인지 데이터로는 구분이 안 된다(전압 채널 없음).
- L-DSF-01 은 95 % 분위 0.59, 최대 0.96 — 한 상이 거의 0 인 파일(채널 탈락 또는 비정상 수집)이 섞여 있다. 참고 분포에서 제외해야 한다.
- 55 kW 의 I₂/I₁ 95 % 0.051(L-PAHU-03S)은 인버터 기본파가 49.6 Hz 라 60 Hz 가정 페이저 추출이 부정확한 영향이 섞여 있다(`i2_over_i1` 는 기본파를 탐색하지만 1 s 창의 분해능 1 Hz).

## M1 과의 비교

지시서의 M1 = **LK-DAD-5W 3.5 kW 4P** 기준. (참고: 저장소 `config/motors/M1.yaml` 은 아직 대표 사양 2.2 kW 4극 1730 rpm 5.0 A 로 돼 있다 — 이번 작업에서 바꾸지 않았다.)

- 겹치는 항목: 4극(1× 29.3 Hz = 1760 rpm, 60 Hz 4극과 일치), 3상 유도전동기(인버터·3상 전류센서 기술), 정격 rpm 1730~1760 대, 가속도 단축 진동·3상 전류 측정 구성.
- 다른 항목: 출력(2.2 kW vs 3.5 kW — 전체 zip 에 **3.7 kW 급 5대**(L-EF-01 정상 13,856 / L-EF-02 그리스 제거 17,360+정상 8,077 / L-EF-04(시청) 정상 23,567 / L-PAC-01 정상 16,744+불평형 16,208 / R-EF-01 축정렬 17,385 파일, 진동만)이 있어 M1 이 정말 3.5 kW 면 2.2 kW 보다 가까운 후보다), 정격 전류(4.7/8.6 A vs 명판 미확인), 부하·구동(공조 팬·벨트 2대 확인 vs 권상 감속기 직결), 전압·결선·제조사·베어링(M1 명판 값 vs 데이터 없음/일부).

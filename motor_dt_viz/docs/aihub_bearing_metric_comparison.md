# 베어링 지표 후보 비교 — 정상 vs 베어링불량 (같은 모터, AI Hub 전체 데이터)

- 파일: 모터·라벨당 최대 2000개 무작위(시드 42), 정지 상태(가속도 RMS ≤ 0.0005 g) 제외. 총 15,647개. 산출: `C:\vigent_data\aihub\L3\bearing_metric_compare.parquet`.
- 결함 모의(가이드라인): L-SF-04·L-PAC-01 **그리스 제거**, L-SF-02 **외륜 소손**, R-CAHU-01S **내륜 소손**. 포락선 배율은 BPFO(외륜) 기준이라 내륜 소손(R-CAHU-01S)은 BPFI 가 더 맞는 지표인데, 비교의 일관성을 위해 세 지표 모두 같은 정의로 냈다.
- 현재 경계(`config/thresholds.yaml bearing_index`): 경고 2배 / 위험 5배. 오탐 = 정상 파일 중 경고 이상(≥2) 또는 위험(≥5) 비율, 미탐 = 불량 파일 중 경고 미만(<2) 비율. kurtosis 는 경계가 없어 같은 숫자(2/5)를 적용하면 의미가 없으므로 **정상 95 % 값을 경고, 99 % 값을 위험으로 둔 가상 경계**로 같이 냈다.
- AUC: 정상 0 / 불량 1 의 ROC AUC (Mann-Whitney). 0.5 = 구분 못 함, 1.0 = 완전 분리.

## 5. 결과 읽기 (실측)

- **소손 2대(M2 외륜, M4 내륜)**: 현재 포락선 배율·kurtosis 모두 AUC ≥ 0.90, kurtosis 는 1.000. 차이는 정상 오탐 — 현재 포락선 배율은 M4 정상에서 100 %가 경고(≥2), 87 %가 위험(≥5)으로 찍힌다(정상 중앙값 6.5). M2 정상도 29 %가 경고.
- **그리스 제거 2대(M1, M3)**: 어느 지표도 못 가른다(AUC 0.2~0.8, kurtosis 는 오히려 불량 쪽이 낮음). 진동이 아니라 온도로 봐야 할 결함.
- **고조파 보정(제가 정의한 방식)은 실패**: 정상 오탐이 줄지 않고(M3 정상 100 % 위험), M4 는 BPFO(3.04×fr ≈ 89 Hz)가 3×fr 고조파와 겹쳐 2×BPFO 창으로 넘어가면서 AUC 0.19. 카탈로그 기하 추정 BPFO 가 고조파와 겹치는 모터에서는 이 접근 자체가 성립하지 않는다.
- **kurtosis 는 '정상 95 %'(≈3.0~3.3)를 경계로 두면 소손은 오탐 5 %·미탐 0 %**, 고정 경계 4 를 두면 오탐 0 %·미탐 0 %. 그리스 제거는 어차피 못 잡는다.

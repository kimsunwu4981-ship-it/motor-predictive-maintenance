## 9. S1·S2 설계 결정 (이 조사에서 도출)

- Parquet 구조: **파일당 1개 Parquet** (`t`, `ch1`[, `ch2`, `ch3`]) + `meta.parquet`. 이유: 전체 데이터가 233만 파일이라 긴 형식 한 테이블은 수백 GB·단일 파일 쓰기 병목이고, 특징 추출은 파일 단위라 파일당 1개가 자연스럽다. float32 (원본 진동 10자리 float → float32 상대오차 ~1e-7, 전류 2^-10 양자화는 float32 로 정확히 표현).
- 포락선 대역: 4 kHz 샘플이라 나이퀴스트 2 kHz → 지시서 기본 2~8 kHz 는 불가. 샘플 주파수의 40 % 상한 규칙으로 **500~1,600 Hz** 를 기본으로 두고 config 로 뺀다.
- 속도 RMS: 10~1,000 Hz 대역통과 후 적분. 단위는 "g 가정"을 `vel_rms_mm_s` 의 docstring·요약표에 명시하고, 설명서로 단위가 확정되면 config 한 줄(`accel_unit`)만 바꾼다.
- 회전 주파수: 어노테이션 rpm(1730/1760) 우선 → `fr_hz` 28.8/29.3 Hz. 4극 60 Hz 동기 1800 rpm 기준 96~98 % 범위 ✔.

가이드라인의 모터별 RMS 라벨링 기준(p.24)은 우리 샘플 모터에 대해 다음과 같다 — 특징 테이블의 `rms` 와 바로 비교할 수 있다.

| 모터 | 역사 | 정상 (진동 RMS g) | 고장 (진동) | 정상 (전류 RMS A) | 고장 (전류) |
|---|---|---|---|---|---|
| L-EF-04 (갑천역A Ch1) | 갑천 | < 0.007 | 없음 | > 3.0 | 없음 |
| L-EF-04 (대전역A Ch8) | 대전 | ≥ 0.0130 | < 0.0130 (불평형) | 1.5~2.9 | 2.9~4 |
| L-SF-04 (갑천역A Ch3) | 갑천 | < 0.0068 | ≥ 0.0068 (베어링) | 2~3.1 | 3.1~5 |
| L-DSF-01 (시청역A Ch7) | 시청 | < 0.0058 | ≥ 0.0058 (축정렬) | 1.5~2.3 | 2.3~3 |
| R-EF-05 (대전역B Ch10) | 대전 | ≥ 0.0077 | < 0.0077 (벨트) | 1.5~2.4 | 2.4~4 |

- **L-EF-04 가 두 역사(갑천·대전)에 각각 있다** — §4 의 "Motor Spec 이 둘" 은 센서 교체가 아니라 **동명이기(同名異機)** 다. 센서ID(0105-0106 대전 / 0105-0160 갑천, LW17-8125 / LW19-3455)로 구분해야 하며, 메타의 `sensor_id` 가 그 역할을 한다.
- 일부 모터는 "정상이 고장보다 RMS 가 높다"(L-EF-04 대전, R-EF-05, R-PAHU-04S) — 라벨이 모터·시기별 RMS 경계로 갈린 것이라 **RMS 크기만으로 정상/고장을 일반화할 수 없다**는 뜻이다. 샘플 요약(§aihub_sample_summary)에서 본 "축정렬불량이 정상보다 낮다"가 이것이다.

## 9. S1·S2 설계 결정 (이 조사에서 도출)

- Parquet 구조: **파일당 1개 Parquet** (`t`, `ch1`[, `ch2`, `ch3`]) + `meta.parquet`. 이유: 전체 데이터가 233만 파일이라 긴 형식 한 테이블은 수백 GB·단일 파일 쓰기 병목이고, 특징 추출은 파일 단위라 파일당 1개가 자연스럽다. float32 (원본 진동 10자리 float → float32 상대오차 ~1e-7, 전류 2^-10 양자화는 float32 로 정확히 표현).
- 포락선 대역: 4 kHz 샘플이라 나이퀴스트 2 kHz → 지시서 기본 2~8 kHz 는 불가. 샘플 주파수의 40 % 상한 규칙으로 **500~1,600 Hz** 를 기본으로 두고 config 로 뺀다.
- 속도 RMS: 10~1,000 Hz 대역통과 후 적분. 단위는 "g 가정"을 `vel_rms_mm_s` 의 docstring·요약표에 명시하고, 설명서로 단위가 확정되면 config 한 줄(`accel_unit`)만 바꾼다.
- 회전 주파수: 어노테이션 rpm(1730/1760) 우선 → `fr_hz` 28.8/29.3 Hz. 4극 60 Hz 동기 1800 rpm 기준 96~98 % 범위 ✔.

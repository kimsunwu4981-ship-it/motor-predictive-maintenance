## 3. 전체 데이터가 말하는 것 (2026-10-08 밤, 37.7만 파일)

- **정상 속도 RMS 는 현재 경고 1.4 mm/s 의 7~21 %(중앙값), 95 % 값도 0.38~0.72 mm/s** — 다섯 용량 모두 경고선 아래 넉넉히 있다. 경고선을 내릴 근거는 있지만(예: 1.0), 가이드라인 자체가 유연 지지 4.5 를 정상 상한으로 쓴 데이터라 1.4 유지가 보수적·설명 가능 (결정 B-1 ②).
- **외륜·내륜 소손(M2 L-SF-02, M4 R-CAHU-01S)은 어떤 지표로도 또렷하다**: 속도 RMS ×3.9 / ×24(M4 는 3.9 mm/s 로 현재 기준 '정비 계획'), kurtosis 2.8 → 94 / 3.1 → 103, 고주파 대역 ×13 / ×18, 포락선 BPFO ×15 / BPFI ×4.4.
- **그리스 제거(M1 L-SF-04, M3 L-PAC-01)는 거의 안 보인다**: 속도 RMS ×1.04 / ×1.15, kurtosis 변화 없음, 포락선 ×1.07 / ×1.5. 윤활 제거 초기엔 결함 주파수가 생기지 않는다 — 온도(베어링 마찰열)로 잡아야 할 결함이며 우리 시뮬레이션 시나리오(베어링 손실 ×5 → 온도)와 맞는 해석.
- **포락선 BPFO 배율은 지금 정의로는 임계값으로 못 쓴다**: 정상에서도 M4 7.0, M5 15~37 (95 % 44) — 기하 추정 BPFO 가 1× 고조파·팬 날개 통과 주파수와 겹쳐 '피크/바닥' 이 커진다. 정상 ≥2배 비율이 70~100 %. 실측 임계는 **kurtosis(정상 ≤4.2, 소손 ≥94)** 나 고주파 대역 RMS 비가 훨씬 깨끗하다.
- 축정렬불량(M1·M2·M3·M5)은 속도 RMS 가 정상과 비슷하거나 낮다(라벨링 기준이 모터·시기별 RMS 경계) — 2× 성분(`a_2x/a_1x`)으로 봐야 한다.
- M3 L-SF-01 정상 63개는 속도 RMS 0.000 (정지 상태 파일). 진동에도 `running` 판정(가속도 RMS 하한)을 두어야 한다.

## 4. 제안 (별도 지시 시 적용, config 무변경)

- 진동 경계 1.4/2.8/4.5 유지. 근거 표는 §2.
- 베어링 지표 정의를 **포락선 피크/바닥 → kurtosis 또는 포락선 피크/고조파 보정**으로 바꾸고, 경고 2/위험 5배는 kurtosis 비(정상 대비)로 재해석(소손 ×30). 윤활 부족형 결함은 베어링 온도로 보완.
- 상태 보드 라벨 '공공 실측 데이터로 보정한 추정값' 은 위 정의 변경을 적용한 뒤에만 쓴다.

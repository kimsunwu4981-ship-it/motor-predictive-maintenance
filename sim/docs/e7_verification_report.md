- 추적 순서: ① 주입 로직 — 측대파 주파수식 fs(1±2ks) 정상 (E5 고정 슬립 테스트에서 0.0 Hz 오차) ② **슬립 계산** — 배치에서는 PhysX 실측 *순시* 슬립을 전류 생성기에 공유하므로, BRB 토크 리플(2sf = 3 Hz)이 만든 속도 리플 → 순시 슬립 리플 → 측대파가 3 Hz로 주파수 변조(FM)됨. k = 2 측대파는 변조 지수가 2배라 피크가 1 bin 갈라져 최대 bin이 이웃으로 이동. 심각도 moderate에서만 관측되는 것은 리플 진폭(2 % T_rated)과 측대파 진폭(−40 dB)의 조합이 분리 임계에 걸리기 때문 ③ 샘플링 — 무관.
- 판단: 순시 슬립 공유(§3 설계 의도)에 따른 **물리적으로 타당한 FM 효과**이며 주입 오류가 아님. 검증 기준(1 bin)을 완화하지 않고 2건을 FAIL로 유지하되 원인 확인 완료로 기록. 학습 데이터로는 유효(라벨·주파수 구조 정상). 필요 시 전류 생성기에 슬립 저역통과(≈1 s 이동평균)를 옵션으로 추가하면 해소 가능(현재 미적용 — 실기 전류에도 FM은 존재).

**최종: 결함 런 70/72 통과(2건 원인 확인), baseline 4/4 통과, 판정 제외(기본파 중첩·<2Δf) 성분은 표에 N/A.**

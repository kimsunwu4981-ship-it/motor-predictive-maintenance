# E3 — 샘플링 설계

| 항목 | 값 | 근거 |
|---|---|---|
| 분석 목표 대역 | **1 kHz** | 결함 주파수 최대: BPFI 96.1 Hz 5차 고조파 ≈ 480 Hz, 전류 3fs = 180 Hz, 2fs+3fr ≈ 178 Hz, 베어링 임펄스 공진 가정 800 Hz |
| physics_hz | **2560 Hz** (dt = 390.6 µs) | 1 kHz × 2.56 |
| 전류 채널 샘플링 | 2560 Hz (물리 step 동기) | fs = 60 Hz 기본파 기준 42.7 샘플/주기, 3fs 까지 충분 |
| 정속(분석) 구간 T | **10 s** | 2sf = 3.0 Hz 측대파 분리: Δf = 1/T = **0.1 Hz** → fs(1±2s) = 57/63 Hz가 기본파 60 Hz에서 30 bin 이격(Hann 창 주엽 폭 4 bin 대비 여유). 회전자 바 파손 4s 측대파(54/66 Hz)도 분리 |
| 기동/정착 | 2 s | t90 ≈ 0.19 s + 정착 여유 |
| 정지 꼬리 | 1 s | 정지 응답 기록 |
| 런 길이 | 13 s → 33 280 샘플 × 13 채널 | |
| 런당 CPU 시간 | ≈ 33 s (앱 기동 15 s + 2560 Hz × 13 s 스텝 ≈ 18 s) | E2 실측 |
| 런당 저장 | ≈ 1.2 MB (npz 압축) | 13 채널 float64 3.5 MB 원본의 ~35 % |
| E6 매트릭스 | (6 결함 × 3 심각도 + 정상) × 2 부하 × 2 시드 = **76 런** | §E6 |
| E6 예상 소요 | ≈ 42 분, ≈ 90 MB | |

Δf 요건 검토: 가장 촘촘한 성분은 BRB 2sf = 3.0 Hz(정격), 반부하(s ≈ 0.0126)에서는 **1.5 Hz** → 15 bin 이격으로 여전히 분리 가능. 무부하(s ≈ 0)는 물리적으로 분리 불가하므로 매트릭스에서 제외하고 50 %/100 % 부하만 사용.
